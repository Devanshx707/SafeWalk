# SafeWalk

SafeWalk is a hackathon starter project focused on **Road Safety and Security at Midnight**.

## Problem Focus
People traveling late at night may face unsafe routes, low visibility areas, and delayed emergency response.

## MVP Goals
- Show safer route awareness for midnight travel.
- Highlight high-risk road zones at night.
- Provide a quick emergency alert action.
- Share simple late-night safety tips.

## Project Template Structure
- `index.html` — basic app layout and sections.
- `styles.css` — simple responsive styling.
- `script.js` — starter interactions for alerts and safety tips.

## Next Steps
- Integrate maps and geolocation APIs.
- Add real-time incident data.
- Connect emergency contacts and backend alerts.
